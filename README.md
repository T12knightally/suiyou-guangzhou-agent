# 穗游 SUIYOU · 广州大学生低预算周末 Agent

从自由填写的校区/广州地址出发，生成半日或一日行程，计算往返交通、餐饮、门票和预留金，检查时间、步行负担，生成雨天安排（主案已全室内时复用）。

**2026-10-14修复版：** 已实现有原文证据的自然语言多轮补参、必去/排除偏好、官方场馆规则、真实步行导航、地图节流与120秒任务预算。53项单元/契约、12合成场景、8真实模型检查点、HTTP 5项、DOM 9项通过。本轮真实地图12个路线事件均成功，样本有限。报告12页，模板24标题，黑色黑体，全框表格。

最新案例85fb96702ab84d8d：省博＋广图，60元/人，14:48返回。省博仍需自行确认预约名额。`evidence/repairs/latest.json` 指向最新完整日志。官网规则仅覆盖2/20场馆，有核验期与适用日期，详见资料维护说明.md。历史联调记录不代表最新功能。

## 30 秒运行
需要 Python 3.10 或更新版本；核心程序仅用标准库，没有 pip 第三方依赖。

```powershell
cd 广州周末Agent
python app.py
```

打开 http://127.0.0.1:8765 。如果 `python` 指向 Microsoft Store，请安装 Python 或用 `py -3 app.py`。可双击 `启动穗游.cmd`；端口冲突时用 `python app.py --port 8766`。

网页默认使用在线查询与首选模型，填写出行条件后直接规划；接口配置和课程演示通过服务端及验证脚本管理。网址分享方法见 `分享与部署说明.md`。

默认输入：广州大学大学城校区、2 人、每人 150 元、09:00 出发、20:00 前回校。校区输入框可以自由填写，列表只是建议。离线测试内置六个常见校区近似坐标；陌生校区可在 API 请求的 `coordinates` 字段补充 `[经度,纬度]`。在线版以高德地理编码确定地址，不使用离线校区别名代替真实地址。

## 开发与测试接口的两个独立选项
| 维度 | 选项 | 说明 |
|---|---|---|
| 数据 | demo | 真实执行本地工具，观察值使用合成场景；不请求外部 API |
| 数据 | live | 高德地理编码/POI/公交与步行路线 + Open-Meteo 天气，缺 Key 明确报错 |
| 引擎 | rules | 确定性筛选与约束求解，模型调用与 Token 均为 0 |
| 引擎 | llm | 真正的 Chat Completions tools 循环；模型选择候选，确定性工具负责核算 |

规划模型不能修改硬约束；需求提取只能按用户原文修改字段。金额和时间由程序核算，没有支付工具。即便模型自然语言声称成功，没有 build_plan 校验结果也不会交付成功行程。

## 在线接入
复制 `.env.example` 为 `.env`，在本地填写：

```dotenv
AMAP_KEY=你的高德Web服务Key
LLM_BASE_URL=https://你的模型服务域名/v1
LLM_MODEL=提供商支持工具调用的模型ID
LLM_API_KEY=你的模型API密钥
```

重启服务后，网页直接使用在线地图与模型规划。接口分别为高德 `v3/geocode/geo`、`v5/place/text`、`v3/direction/transit/integrated`、`v3/direction/walking`，以及 Open-Meteo `/v1/forecast`。模型提供商须支持 `POST /chat/completions`、`tools` 和 `tool_calls`。具体账户权限、价格、限额请按提供商文档检查，代码不代表已获服务权限。基础 URL 只接受 HTTPS。

当前首选 qwen3.8-flash，显式关闭思考模式；可选 DeepSeek Flash。两者工具协议均已实际验证，Qwen 已完成本轮8个真实模型检查点；人民币费用与大规模模型正确率仍未测量。切换模型不会自动故障转移，也不自动追加付费请求。

在线地图可能不返回门票、日期对应开放时间、预约规则。系统保留空值，按每个地点 30 元、每段未知交通 10 元设置**规划占位额度**，这不是票价、不是上界保证。最终仍为 `draft`；不得对外声称预算或开放已确认。营业时间文本不自动解释为有效营业承诺。路线是查询时估算，公交每段增加15分钟缓冲，步行增加3分钟缓冲，不是未来日期班次查询。

## 核心约束与状态
- `per_person = 门票 + 全部路线(含返程) + 35元餐饮饮水 + 15元预留`，同行总额等于每人额度乘人数。
- 每点停留完整落入已知开放区间；开放未知不编造区间，标记 `unknown_hours`。
- 返程不得超过 `end`，不支持跨午夜；轻松节奏总步行估算上限 90 分钟，普通节奏 150 分钟。
- 最多六个候选，模型提交1-3个；比较同片区双点的两个顺序，再尝试单点，限制跨城折返；不是全局最优路线算法。
- 降雨选室内；雷暴等严重天气暂停；闭馆移除；路线不可验证时不捏造班次补齐。
- 会话在本机进程内保存结构化条件；引用核对后增量更新，非法请求不污染会话，旧消息不重放。重启会话丢失，行程 JSON 保留；不存 API 密钥到 Trace。
- 状态包括 `needs_input / invalid / rejected / out_of_scope / unavailable / needs_configuration / suspended / no_feasible_plan / draft`。

## Trace 与安全
每个工具事件保留名称、输入、输出、耗时、时间戳、成功标记；Decision 是可审计的程序决策摘要，不是隐藏思维链。原始 Trace 保存在服务端 `runs/` 文件与 API 响应中；用户页面只展示出行信息，并提供可阅读的 TXT 行程单和打印功能。工具白名单、参数类型检查、规划模型最多8轮/12次调用，需求理解另最多1轮，最多2次build_plan、地图请求上限 40 次；数据请求 6 秒超时且最多重试一次，模型请求 45 秒超时且不自动重试。外层调用可触发多个路线子调用，二者计数不同。

客户端做 HTML 转义；HTTP 只绑定 127.0.0.1，POST 检查 Host/Origin，限制请求体 16KB、并发 4；密钥只在服务端。用户注入正则仅是早期筛查，关键防线是模型无法修改的预算/时间、白名单和受限执行器。项目没有支付、Shell、任意网络 URL 工具。已有全局地图节流与120秒尽力而为的任务预算，非独立进程强杀。上线仍需鉴权、用户配额、持久存储、隐私留存及更多模型攻防与并发测试。
